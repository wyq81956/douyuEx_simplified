# B站 v1.6.1：修复网页全屏视频左移和中间空隙

修复开启右侧弹幕池后，网页全屏时视频向左偏移、视频与弹幕池之间露出原网页的问题。

B站原生网页全屏固定的是外层，内层播放器仍为相对定位。现将开启弹幕池时的内层明确固定在可视区域左上角，按视口宽度给右侧弹幕池留位；退出网页全屏或收起侧栏后恢复原生布局。

用修正后的原生嵌套结构复现了旧版左移与空隙，并验证新版左右边界贴合、T 键退出/再次进入、稍后观看、高分辨率和窄窗口场景；原有弹幕、快捷键及直播回归检查通过。真实页面更新后的效果待用户确认。

更新后刷新视频页即可，原有设置保留。附件包含 B站 `bilibiliex.user.js` v1.6.1 和沿用版本的斗鱼 `douyuEx_simplified.user.js` v1.5.8，继续支持自动更新。
