# B站 v1.6.0：视频右侧同步弹幕池

新增默认开启的“视频右侧弹幕池”，可在 BilibiliEx 设置中独立关闭。

- 视频网页全屏时，视频在左，随播放进度出现的弹幕在右；画面飘屏弹幕继续由播放器原有开关控制。
- 暂停不推进，跳转后重新对齐，支持视频/分 P 切换及稍后观看。
- 向上翻看暂停自动滚动，点“回到最新弹幕”恢复跟随；加载失败可点“重载”。
- T 键退出网页全屏后恢复原布局。窄于 900px 或进入浏览器全屏时收起弹幕池。

侧栏独立读取普通弹幕，暂不继承网站屏蔽词、智能屏蔽和密度设置；最多保留 250 行，跳转后回看 60 秒。不新增油猴权限，原有设置保留。

解析与时间轴检查、原有功能回归，以及本机 Chromium 的暂停、跳转、分 P/视频切换、翻看/恢复跟随、503 重载、输入保护、T 键恢复布局、稍后观看和窄窗口场景检查通过。已核对官方播放器字段与公开接口；用户真实页面最终效果待试用确认。

附件同时提供 B站 `bilibiliex.user.js` v1.6.0 和沿用已发布版本的斗鱼 `douyuEx_simplified.user.js` v1.5.8，继续兼容各自的自动更新地址。
