# B站 v1.7.0：暗色弹幕池、宽度可调、隐藏时间戳

- 右侧弹幕池改为暗色背景，标题栏、按钮、边框和滚动条配套调整。
- 隐藏每条弹幕的时间戳和顶部当前时间，只展示弹幕正文，仍按视频时间同步。
- 拖动视频与弹幕池之间的分隔线调整宽度，松手自动保存；双击或 Home 恢复默认。
- 分隔线聚焦后，左右方向键微调 10px，Shift 加方向键调整 50px；Esc 取消拖动。
- 宽度范围 240–600px，并为视频保留至少 640px；窗口收窄时临时限制宽度，放大后恢复偏好。

宽度保存与取消、重新加载、复位和窗口限制通过模拟检查，暗色与隐藏时间戳已在本地渲染中观察。Computer Use 因无法可靠识别测试窗口的浏览器地址而中止原生鼠标验证；实际拖动交互待试用确认。原有弹幕、快捷键和直播回归检查通过。
