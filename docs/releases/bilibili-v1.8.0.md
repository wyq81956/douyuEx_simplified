# B站 v1.8.0：弹幕池字体与字号设置

- “BilibiliEx 设置”新增视频右侧弹幕池字体和字号选项。
- 字体可选系统默认、微软雅黑、黑体、宋体和楷体；未安装的字体使用系统替代字体，不额外下载字体。
- 字号支持 12–32px，默认沿用 14px；设置面板内提供文字预览。
- 点击“保存并刷新”后生效，刷新和重启浏览器后保留；取消或关闭设置不保存预览修改。
- 仅调整右侧视频弹幕正文，标题栏、画面飘屏弹幕和直播弹幕不受影响，原有开关和宽度偏好保留。

语法检查及设置预览、保存与取消、重新读取、非法存储回退、侧栏样式应用、宽度、弹幕、快捷键与直播模拟回归检查通过；真实页面显示效果待更新后试用。

附件包含 B站 `bilibiliex.user.js` v1.8.0 与斗鱼 `douyuEx_simplified.user.js` v1.5.8，沿用已有自动更新地址。
