# B站 v1.5.0：T 键切换网页全屏

B站脚本新增默认开启的“T 键切换网页全屏”，可在油猴菜单 → BilibiliEx 设置中独立关闭。

- 普通视频、稍后观看播放页和数字直播间页面，按 T 进入网页全屏，再按 T 退出。
- 输入框、可编辑区域、对话框和设置面板内不触发，支持识别 Shadow DOM 内的输入框。
- 跳过组合键、输入法组合输入、长按重复、视频小窗和浏览器全屏状态。
- 使用网站原生按钮切换；手动按 T 会停止当前页面这轮自动进入操作，避免退出后被自动切回。

此次 Release 提供 `bilibiliex.user.js` v1.5.0 和 `douyuEx_simplified.user.js` v1.5.8 两份附件，继续支持各自的正式版自动更新地址；斗鱼附件沿用已发布版本。B站原有设置保留，新快捷键默认开启。

两份脚本的语法检查通过。B站快捷键、页面分流、直播网页模式和最高画质模拟回归检查通过；快捷键实际页面效果待试用确认。
