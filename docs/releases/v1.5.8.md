# 斗鱼 v1.5.8 + B站 v1.4.1

本次正式 Release 同时提供两个独立油猴脚本：

- `douyuEx_simplified.user.js`：斗鱼 v1.5.8，本次仅更新版本号，功能和设置沿用 v1.5.7_1。
- `bilibiliex.user.js`：B站 v1.4.1，新增与斗鱼相同的正式 Release 自动更新地址。

B站脚本包含动态悬浮资料卡屏蔽、视频和稍后观看自动网页全屏，以及直播自动网页模式、自动最高画质、弹幕等级/粉丝牌/特殊称号屏蔽、弹幕池顶部屏蔽。六个开关通过油猴菜单的“BilibiliEx 设置”集中调整，点击“保存并刷新”应用修改。

直播自动网页模式会等待页面与视频就绪，确认实际布局后才结束；按钮提示变化却布局未生效时会有限重试。自动最高画质选择网站提供的最高可用选项，手动切换后不强制恢复。

## 安装与更新

- [斗鱼正式版](https://github.com/wyq81956/douyuEx_simplified/releases/latest/download/douyuEx_simplified.user.js)
- [B站正式版](https://github.com/wyq81956/douyuEx_simplified/releases/latest/download/bilibiliex.user.js)

B站 v1.4.0 及更早版本的用户需先安装或覆盖更新一次，启用篡改猴自动更新检查；此后两份脚本分别通过最新正式 Release 的同名附件自动更新。原有脚本名称、namespace 和设置保留。

## 验证

两个脚本的 JavaScript 语法检查通过；B站页面分流、直播模式恢复和最高画质模拟回归检查通过。设置面板此前已通过本地浏览器的读取旧设置、取消、Esc、点击面板外关闭及保存刷新检查。直播网页模式的时序修复和自动最高画质仍待实际使用反馈。
