# douyuEx_simplified

基于 [小淳的 DouyuEx](https://github.com/qianjiachun/douyuEx) 提取功能、独立维护的斗鱼直播间增强脚本，运行于 Tampermonkey。

原作者已停止维护，本仓库按个人观看需求逐步精简。原版源码保留作参考，实际使用和维护的脚本位于 [simplified/douyuEx_simplified.user.js](simplified/douyuEx_simplified.user.js)。

**当前版本：1.5.4**。无需安装 npm 依赖或编译，没有外部库、统计代码或脚本自身发起的网络请求。

## 当前功能

油猴菜单只保留 **“DouyuEx 设置”** 一个入口，点击后在页面打开设置面板。面板内有八个开关，默认开启，点击 **“保存并刷新”** 后生效；取消、Esc 或点击面板外侧会放弃未保存的开关改动。

| 开关 | 效果 |
| --- | --- |
| 自动网页全屏 | 进入直播间后自动点击网页全屏按钮，让播放器铺满网页区域 |
| 自动最高画质 | 自动选择播放器画质列表的第一项，沿用原版最高画质排序约定 |
| 简洁模式 | 统一控制下列六项页面整理效果 |
| 屏蔽刀塔助手 | 隐藏技能/物品悬停热区、描述弹窗、助手入口和提示窗；独立于简洁模式 |
| 拖动调整弹幕池 | 拖动视频与弹幕池之间的分隔线调整宽度，松手保存，双击恢复网站默认宽度 |
| 滚轮调音量 | 鼠标放在播放器音量按钮或滑条上，向上滚增加 5%，向下滚减少 5%，范围 0–100% |
| 下播不跳转 | 自动关闭下播推荐弹窗，阻止该弹窗的自动跳转，保留当前直播间 |
| 关注页过滤 | 仅在“我的关注”页面隐藏顶部 banner，以及标有“上次直播”“预告”“轮播”的房间卡片 |

简洁模式包含：

- **隐藏礼物栏**，扩展视频区域，并隐藏相关 PK、点赞浮层，保留视频播放控制栏。
- **拉高弹幕框**，隐藏日榜/周榜和房间活动区域。
- **隐藏弹幕前缀**，包括粉丝牌、贵族和用户等级图标，保留昵称与正文。
- **屏蔽进场弹幕**，隐藏弹幕框底部的进场信息区域。
- **屏蔽弹幕背景**，去掉匹配的背景、装饰图片和特效前缀。
- **隐藏广告与推广**，包括横幅、浮动广告、二维码、游戏推广和活动引导等。

这六项一起开启或关闭，不再提供分项开关。原版的签到、送礼、账号切换、画中画等功能尚未加入精简脚本。

## 安装与更新

1.5.4 新增“关注页过滤”，独立于简洁模式，默认开启。覆盖现有脚本并刷新 [我的关注](https://www.douyu.com/directory/myFollow) 页面即可，已有设置保留。

1.5.3 将七个开关和“恢复弹幕池默认宽度”集中到页面设置面板，油猴菜单只保留一个入口，已有开关与宽度设置保留。

1.5.2 新增“滚轮调音量”和“下播不跳转”，两个独立开关默认开启，已获个人实际试用反馈正常。

1.5.1 已合并弹幕池拖动功能，经个人实际试用确认正常。试用过拖动 Beta 的用户请停用 Beta，用正式版文件覆盖原正式版并启用。正式版与 Beta 设置独立，正式版会保留原有设置，弹幕池宽度需重新拖动保存一次。两个 Beta 脚本及其说明文件已从当前版本移除，历史内容仍可在 Git 提交记录中查看。

1. 在浏览器中安装并启用 Tampermonkey。
2. 打开 [脚本源码](simplified/douyuEx_simplified.user.js)，点击 **Raw** 获取完整内容。也可直接打开 [原始脚本文件](https://raw.githubusercontent.com/wyq81956/douyuEx_simplified/master/simplified/douyuEx_simplified.user.js)；若油猴弹出安装页，按提示安装。
3. 若没有弹出安装页，在油猴中新建脚本，用完整源码替换默认内容并保存。
4. **停用原版 DouyuEx 和其他重复安装的精简版**，再刷新斗鱼直播间，避免重复触发全屏切换。
5. 点击浏览器中的油猴图标，选择 **“DouyuEx 设置”**，在面板中调整开关后点击 **“保存并刷新”**。面板里的“恢复弹幕池默认宽度”按钮立即复位宽度，也可双击分隔线复位；宽度复位不受“取消”影响。

更新时用最新代码覆盖油猴中已有的精简脚本并保存，不要额外启用第二份。当前没有内置更新检查服务，按上述方式手动更新。

1.4.0 已合并最高画质切换 Beta 的优化。试用过 Beta 的用户请停用 Beta，更新并启用正式版；两个版本的设置独立，正式版保留原有设置。

从旧版升级到 1.3.x 时，自动全屏和最高画质设置会保留；合并后的简洁模式默认开启，旧的六个分项设置不再参与判断。

## 实现与适用范围

- 脚本匹配 `www.douyu.com`。自动全屏和直播间整理等待直播 video 节点；弹幕池拖动通过播放器与弹幕区结构确认直播间。关注页过滤单独按路径启用，不等待播放器。不是鱼吧或点播站的全站增强脚本。
- 设置面板按需创建，通过 Shadow DOM 隔离网站样式，原生 `dialog` 提供遮罩、焦点管理和 Esc 关闭。关闭时移除面板，保存开关仍使用原来的油猴存储键；复位宽度即使在拖动功能关闭时也可清除保存的偏好。需要支持 Shadow DOM 和 `dialog` 的现代浏览器。
- 关注页过滤仅在 `/directory/myFollow`（也支持末尾 `/` 和查询参数）启用：CSS 隐藏 `.layout-Banner`；检查 `div.layout-Cover-card` 内的 `p` 是否包含“上次直播”或“预告”，或 `span` 是否包含“轮播”，匹配则隐藏整张卡片。对应原 Adblock 三条规则，不通过接口判断主播状态。监听异步加载、翻页、class 和文字变化，100ms 合并扫描；卡片更新后不再匹配时恢复显示，不取消关注或删除网站数据。关闭开关并保存刷新即可恢复页面。
- 自动全屏每秒检查一次，最多尝试 100 次，找到目标后停止。
- 最高画质启动时立即检测，通过菜单变化监听和 250ms 轮询寻找选项，不再额外等待 video 节点。选中状态保持 2 秒后停止；点击至少间隔 2 秒，最多 5 次，总等待上限 100 秒。用户手动点击画质菜单时停止自动切换。
- 画质确认针对菜单选中状态，不代表直播流已经缓冲完成；停止后不会持续覆盖用户手动选择。控制台筛选 `DouyuEx 画质` 可查看检测、点击和停止耗时。
- 简洁模式注入一份 CSS，后续加载的匹配元素也会被隐藏。广告隐藏是 **CSS 隐藏页面元素**，不会阻止广告请求、下载或执行。
- 屏蔽刀塔助手单独注入 CSS，隐藏覆盖在视频上的技能/物品鼠标热区及其弹窗，不修改斗鱼账号设置，不停止助手后台的数据请求。关闭该开关并刷新可恢复助手；播放器控制栏、主播战绩和第一视角入口不在屏蔽范围内。1.5.0 的选择器已核对 9999 直播间 DOM 和公开组件源码，并经个人实际试用确认屏蔽有效。
- 弹幕池拖动使用新版布局的 `--stage-sidebar-width` 变量，视频与工具栏同步调整。向左拖加宽，向右拖缩窄，范围 220–600px，并保留网站规定的最小视频宽度。支持普通模式和弹幕池可见的网页全屏；窄窗口临时限制宽度，窗口变大后恢复保存的偏好，弹幕池隐藏时不显示分隔线。分隔线获得键盘焦点后，左右方向键微调 10px，Shift 加方向键微调 50px，Home 复位。只接入已核对的新版布局。
- 滚轮调音量只处理直播播放器的音量控件，其他区域正常滚动；Ctrl/Meta 加滚轮保留浏览器缩放。调至 0 时静音，调至非零时取消静音；已静音但保留音量时，沿用原版从记住的音量继续增减。同步滑条、百分比和静音图标，只更新斗鱼已有的音量存储项。支持控件延迟出现或重建，新版播放器结构与音量控件已核对 9999 直播间。
- 下播不跳转沿用原版的 `.ClosingRecommend .dy-ModalRadius-close-x`，立即检查并在观看期间每秒尝试关闭可见的下播推荐弹窗。不是全站导航拦截，不影响手动打开其他直播间。依赖网站保留该弹窗及关闭逻辑；与滚轮调音量均已获个人实际试用反馈正常。
- 最高画质只选择网页提供的选项，不绕过登录或付费权限。
- 页面适配依赖斗鱼的 DOM 类名；网页改版后可能需要更新选择器。部分全屏布局规则使用 CSS `:has()`，需要支持它的浏览器。
- 已进行 JavaScript 语法和模拟逻辑检查（`node tests/barrage-resize.test.cjs`、`node tests/playback-controls.test.cjs`、`node tests/follow-filter.test.cjs`）；设置面板在本地浏览器测试页验证了旧设置读取、取消、Esc、保存刷新、宽度复位及样式隔离。弹幕池拖动、滚轮调音量和下播不跳转经个人实际试用确认正常，最高画质优化经个人实际试用反馈略有改善。关注页过滤经个人实际试用确认正常；未完成跨浏览器和各类直播间的完整验证。

## 自行维护

直接修改 [精简脚本](simplified/douyuEx_simplified.user.js)，再将完整代码同步到油猴。**精简版不使用原项目的 `npm run build`**，该命令仍对应保留的原版构建流程。

新增广告隐藏规则时，在脚本的 `applySimpleMode()` 中找到广告/推广 CSS 列表，添加实际元素的选择器，例如：

```css
/* 示例：需替换成通过开发者工具确认的广告容器类名 */
.NewPromotionBanner { display: none !important; }
```

先在浏览器开发者工具中确认隐藏的是广告容器，避免使用 `img`、`.container` 等范围过大的选择器。规则随“简洁模式”一起生效。
