# douyuEx_simplified

## 项目来源

基于 [小淳的 DouyuEx](https://github.com/qianjiachun/douyuEx) 精简并独立维护的斗鱼增强脚本，运行于 Tampermonkey（油猴）。原作者已停止维护，本项目保留原版源码，按个人观看需求提取和改进功能。

当前版本：**1.5.7_1**，无需编译。

## 现有功能

| 功能 | 说明 |
| --- | --- |
| 自动网页全屏 | 进入直播间后让播放器铺满网页区域 |
| 自动最高画质 | 自动加载画质选项并选择最高画质，无需先移入鼠标；手动选择后停止干预 |
| 简洁模式 | 隐藏礼物栏、广告与推广，拉高弹幕框，屏蔽进场信息、弹幕背景及粉丝牌、等级、头衔等前缀装饰 |
| 屏蔽刀塔助手 | 隐藏 Dota 2 技能、物品的悬停描述和助手入口 |
| 调整弹幕池宽度 | 拖动视频与弹幕池之间的分隔线，松手保存，双击恢复默认 |
| 滚轮调音量 | 鼠标放在音量按钮或滑条上滚动，每次增减 5% |
| 下播不跳转 | 自动关闭下播推荐弹窗，留在当前直播间 |
| 关注页过滤 | 隐藏“我的关注”顶部横幅及标有“上次直播”“预告”“轮播”的房间卡片 |
| 镜像画面 | 播放器右键菜单切换水平镜像 |
| 旋转画面 | 播放器右键菜单每次顺时针旋转 90°；可与镜像组合，刷新后复位 |

## 如何使用

1. 在浏览器安装并启用 **Tampermonkey**。
2. 打开 [最新发布的脚本](https://github.com/wyq81956/douyuEx_simplified/releases/latest/download/douyuEx_simplified.user.js) 安装。如果没有弹出安装页，可在油猴中新建脚本，粘贴 [脚本源码](simplified/douyuEx_simplified.user.js) 的 **Raw** 完整内容并保存。
3. 停用原版 DouyuEx 和其他重复脚本，刷新斗鱼直播间。
4. 点击油猴图标 → **DouyuEx 设置**，调整开关后点击 **保存并刷新**。八个设置开关默认开启，镜像和旋转直接在播放器右键菜单使用。

支持订阅正式 Release：在篡改猴中启用自动更新检查，发布更高版本号的正式版后即可更新。旧版用户先通过上面的安装链接更新一次（或用完整代码覆盖已有脚本），再刷新页面，原有设置保留。

[详细说明](simplified/README.md) · [版本发布](https://github.com/wyq81956/douyuEx_simplified/releases)
