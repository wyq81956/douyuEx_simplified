# youtubeEX

版本 **1.0.0**，独立油猴脚本，无需编译。将 YouTube 的影院模式扩展成网页全屏，播放器占满浏览器内容区的宽度和高度。

## 安装

在 Tampermonkey 中新建脚本，用 [youtubeex.user.js](youtubeex.user.js) 的完整内容覆盖默认代码并保存，然后刷新 YouTube。当前供本地安装，尚未发布 Release 自动更新地址。

## 使用

- 打开普通视频或直播的 `/watch?v=…` 页面，点击播放器的 **影院模式** 按钮，或使用 YouTube 原生 **T** 键切换。
- 影院模式下隐藏顶部导航和搜索栏，播放器铺满当前网页视口；浏览器地址栏、标签栏仍保留。
- 标题、简介、评论、推荐及直播聊天仍在播放器下方，可以向下滚动查看。需要顶部搜索栏时，退出影院模式即可。
- 原生播放控制、字幕、音量和全屏按钮照常保留。画面保持比例，不拉伸、不裁切；画面与窗口比例不同时，仍可能有黑边。
- 再次按 **T** 或点击影院按钮即可恢复普通布局。进入浏览器全屏、小窗播放，或站内离开视频页时停止覆盖，返回影院模式时重新生效。
- 油猴菜单中的 **youtubeEX：关闭影院模式增强** 可停用增强并刷新；重新开启后同样刷新，设置会保存。

脚本默认开启增强，**不自动切入影院模式**，由 YouTube 原生按钮和快捷键控制。不作用于 Shorts、嵌入播放器或移动版页面，不更改画质与播放状态。

## 实现与验证

根据 `ytd-watch-flexy` 的 `theater` / `fullscreen` 状态，在普通视频路由下启用 CSS，移除影院容器的高度上限并使用 `100dvh`。监听原生页面导航、全屏事件和播放器节点替换，支持站内切换视频。退出时移除增强标记，恢复网站原有样式。

已通过语法检查及本地模拟的延迟挂载、切换影院模式、全屏、小窗、站内导航和页面恢复检查；用户已在真实 YouTube 页面试用并确认正常。YouTube 改版或不同实验布局可能需要调整选择器。

在仓库根目录运行 `node tests/youtube-theater.test.cjs` 可复查模式切换逻辑。
