# B站附属脚本

版本 **1.8.0**，一个油猴脚本包含动态、视频和直播间增强功能，八个开关默认开启，分别保存，无需编译。1.8.0 新增弹幕池字体、字号和设置内预览；1.7.1 缩小行间距、标题栏和左右留白，删除同步说明及底部提示，隐藏滚动条并保留滚动功能；1.7.0 将右侧弹幕池改为暗色、隐藏时间戳，并支持拖动和保存宽度；1.6.1 修复网页全屏时视频左移、弹幕池与视频之间露出原网页的问题；1.6.0 新增视频网页全屏模式的右侧同步弹幕池，保留原有飘屏弹幕；1.5.0 新增 T 键切换视频、稍后观看和直播的网页全屏，可独立关闭；1.4.1 添加 GitHub 正式 Release 自动更新地址，与斗鱼脚本一起发布；1.4.0 已将六个开关集中到与斗鱼脚本相同形式的设置面板，保留原有设置；1.3.2 已修复直播自动网页模式过早点击、仅按钮提示变化却未进入布局时误判成功的问题；1.3.1 已将直播弹幕中的特殊称号纳入等级和粉丝牌屏蔽；1.3.0 已支持直播间自动最高画质；1.2.0 已支持直播间自动网页模式、弹幕等级和粉丝牌屏蔽、弹幕池顶部屏蔽；1.1.1 已支持“稍后观看”播放页。

## 安装与更新

使用同目录 [bilibiliex.user.js](bilibiliex.user.js) 的完整源码。在 Tampermonkey 中编辑已有脚本，用完整新代码覆盖并保存，再刷新对应页面。文件名统一为 `bilibiliex.user.js`，沿用原来的脚本名称、namespace 和原有存储键，原有开关状态自动显示在设置面板中。

首次使用时，安装并启用 Tampermonkey，打开 [最新正式版安装链接](https://github.com/wyq81956/douyuEx_simplified/releases/latest/download/bilibiliex.user.js)。如果没有弹出安装页，在 Tampermonkey 中新建脚本，粘贴完整源码并保存即可。如果试装过单独的“B站视频 - 自动网页全屏”脚本，请停用或删除它。

从 1.4.0 或更早版本升级时，请先通过上面的正式版链接安装或覆盖更新一次。启用篡改猴自动更新检查后，`@updateURL` 和 `@downloadURL` 会从最新正式 Release 的 `bilibiliex.user.js` 附件检查版本和下载更新，不跟随分支提交；沿用原有名称、namespace 和存储键。每次联合发布均附带斗鱼和 B站两个脚本，两个脚本按各自版本号更新。

点击油猴图标 → **BilibiliEx 设置**，在页面内的设置面板调整以下八个独立开关，然后点击 **保存并刷新**。设置在刷新和重启浏览器后保留；点击 **取消**、按 Esc 或点击面板外部会关闭且不保存修改。重复打开会聚焦已有面板。

- 动态资料卡屏蔽
- 视频自动网页全屏
- 直播自动网页模式
- 直播自动最高画质
- 直播弹幕装饰屏蔽（等级、粉丝牌和特殊称号）
- 直播弹幕池顶部屏蔽
- T 键切换网页全屏
- 视频右侧弹幕池

面板采用 Shadow DOM 隔离网站样式，原生对话框支持键盘操作、焦点管理和 Esc 关闭。已在本地浏览器验证六个开关的默认值和旧设置读取、取消丢弃修改、保存刷新后状态保留及 Esc 关闭。

## 视频右侧同步弹幕池

油猴菜单 → **BilibiliEx 设置**，可调整 **视频弹幕池字体** 和 **视频弹幕池字号**。字体提供系统默认、微软雅黑、黑体、宋体、楷体；需要本机已安装，未安装时自动使用替代字体。字号范围 12–32px，默认 14px；面板内文字预览随选择更新，点击 **保存并刷新** 后应用并保留。取消或关闭不保存修改。仅调整右侧弹幕正文，标题栏、原生飘屏弹幕和直播弹幕不受影响。


默认开启，在普通视频和“稍后观看”播放页进入网页全屏时显示：左边保留视频和原生输入框，右边显示随视频进度逐条出现的普通弹幕。画面上的飘屏弹幕继续由播放器原有开关控制；设置面板可独立关闭“视频右侧弹幕池”。按 T 或原生按钮退出网页全屏后恢复原布局，浏览器全屏、视频小窗和窗口宽度不足 900px 时收起。右侧弹幕池采用暗色背景，仅显示弹幕正文，不显示逐条时间戳或顶部当前时间。采用紧凑的单行标题栏和半间距弹幕行，缩小左右留白，无底部发送提示；隐藏滚动条，保留滚轮、触控和键盘滚动。默认宽度随窗口变化，为 260–360px；可以拖动视频和弹幕之间的分隔线调整，松手后自动保存。可调范围 240–600px，同时为视频保留至少 640px；窗口收窄时临时限制显示宽度，放大后恢复已保存偏好。双击分隔线或按 Home 恢复默认；分隔线获得焦点后用左右方向键调整 10px，Shift 加方向键调整 50px，Esc 取消正在进行的拖动。1.6.1 将视频内层明确固定在视口左上角，并按视口宽度扣除弹幕池，避免原生相对定位把视频左移；退出后恢复网站原生布局。

- 弹幕按时间戳展示，暂停时不推进，不提前显示未来弹幕。首次进入和跳转后展示当前进度之前 60 秒内的内容，此后随播放追加，最多保留 250 行。
- 监听视频时间和跳转事件，URL 中的视频编号或分 P 改变时重新读取；旧请求会取消，避免旧视频弹幕混入。支持不刷新页面的换视频和换分 P。
- 默认跟随最新弹幕；向上翻看时停止自动滚动，点击“回到最新弹幕”重新对齐并恢复跟随。也支持聚焦滚动区后用 Home/End 等按键翻看。
- 读取 B站视频资料和分段普通弹幕接口，按需请求当前段并在临近边界时预取；限制缓存和并发，请求 15 秒超时，失败后可点“重载”。不新增油猴权限或外部依赖。
- 这是独立的播放进度弹幕列表，暂不继承播放器的屏蔽词、智能屏蔽和密度设置；不显示用户名或头像，不展示高级/代码弹幕，不提供新的发送入口。新发送的弹幕在重载数据后才能读到。

已核对当前官方播放器字段和接口响应，并通过本地浏览器的暂停、跨段跳转、分 P/视频切换、翻看历史与恢复跟随、接口失败重载、T 键恢复布局、稍后观看和窄窗口场景检查；真实 B站页面的最终布局及账号过滤差异仍待试用。详见 [验证记录](../docs/bilibili-danmaku-panel.md)。

运行 `node tests/bilibili-danmaku.test.cjs` 检查弹幕解析、时间边界和宽度限制；运行 `node tests/bilibili-sidebar-resize.test.cjs` 检查模拟拖动、保存、取消、复位、重新加载及窗口收窄行为；运行 `node tests/fixtures/bilibili-sidebar-preview.cjs` 后打开终端中的本机地址，可手动复查浏览器场景（纯测试数据）。

## 快捷键：T 切换网页全屏

在普通视频、稍后观看播放页和数字直播间页面，按一次 **T** 进入网页全屏，再按一次退出。大写 T（Caps Lock）同样可用；此开关默认开启，在“BilibiliEx 设置”中可单独关闭，关闭自动进入网页全屏也不影响手动快捷键。

通过网站原生按钮切换；直播复用“网页模式”提示识别。按键会停止当前页面这轮自动进入操作，避免手动退出后被强制切回。动态页、浏览器全屏、视频小窗及播放器未就绪时跳过。输入框、可编辑区域、设置面板及其他对话框内不触发，Shadow DOM 内的输入框也会识别；组合键、输入法组合输入及长按重复不触发。连续切换至少间隔 350ms，离页清理监听。

已通过视频、稍后观看和直播切换、输入保护、长按抑制、自动进入冲突及离页清理的模拟回归检查；真实页面效果待试用。仓库根目录运行 `node tests/bilibili-hotkey.test.cjs` 可复查。

## 动态：屏蔽悬浮用户资料卡

参考本项目斗鱼精简版的 CSS 屏蔽思路，在 `https://t.bilibili.com/*` 隐藏悬浮用户资料卡。刷新 [B站动态页](https://t.bilibili.com/)，把鼠标移到动态作者、转发作者等用户的头像上检查效果。

### 实现与范围

- 注入 CSS，隐藏 `.bili-user-profile` 和 `bili-user-profile`；不改动头像、昵称和它们的链接，也不拦截鼠标事件。
- 页面加载初期注入，规则自动作用于后续异步加载、滚动追加及重建的资料卡。
- 仅在 `t.bilibili.com` 顶层页面生效，不影响视频页或个人空间页。
- 无外部依赖、网络请求或账号设置修改。页面自身可能仍请求资料卡数据，本脚本只隐藏展示。

选择器参考 [B站共同关注快速查看的作者源码](https://greasyfork.org/zh-CN/scripts/428453-b%E7%AB%99%E5%85%B1%E5%90%8C%E5%85%B3%E6%B3%A8%E5%BF%AB%E9%80%9F%E6%9F%A5%E7%9C%8B/code) 的 `initDynamic()` 和 `initBiliUserProfile()`。已通过 JavaScript 语法和启用/停用逻辑检查，真实页面效果仍待试用；B站改版后可能需要调整选择器。

## 视频：自动网页全屏

在普通视频页 `https://www.bilibili.com/video/*` 和“稍后观看”播放页 `https://www.bilibili.com/list/watchlater/` 等待视频就绪，自动点击网站的网页全屏按钮，让播放器铺满浏览器网页区域。与资料卡屏蔽共用一个脚本，按页面地址启用对应功能；`bvid`、`oid` 等查询参数不影响启动判断。

### 行为与验证

- 通过 `.bpx-player-container` 的 `data-screen` 检查模式，再点击 `.bpx-player-ctrl-web`；已进入网页全屏或浏览器全屏时直接停止。
- 视频加载到元数据就绪后才尝试；不要求自动播放，也不修改画质、声音或播放状态。
- 每 500ms 检查一次，最多等待 100 秒；最多点击 3 次，至少间隔 2 秒。成功后结束，手动退出后不强制恢复。页面离开时清理计时器和监听。
- 初始化期间手动点击网页全屏、全屏或宽屏按钮，或在非输入区域使用 Esc/W/F/Q，会停止本次自动操作。
- 每次完整加载页面执行一轮；站内不刷新页面的换集或换视频不重新启动。覆盖普通视频页和“稍后观看”播放页，番剧页面暂不覆盖。

按钮和模式值参考 [bilibili H5播放器快捷操作的作者源码](https://greasyfork.org/en/scripts/26939-bilibili-h5%E6%92%AD%E6%94%BE%E5%99%A8%E5%BF%AB%E6%8D%B7%E6%93%8D%E4%BD%9C/code)。已检查语法及延迟加载、重复点击、已有全屏、手动操作和超时清理逻辑，并检查“稍后观看”地址的元数据匹配和功能启动；真实 B站页面效果尚待试用，网页改版可能需要调整。

## 直播间增强

适用于 `https://live.bilibili.com/数字房间号`，兼容 `/blanc/数字房间号`、末尾斜杠及查询参数；不处理直播首页和活动页。

- **自动网页模式**：等待页面加载完成、视频元数据就绪并持续稳定 2 秒后，通过提示文字识别并点击“网页模式”，保留网站原有播放器与弹幕池布局。成功须同时满足 `body.player-full-win`、`#fullscreen-container` 固定定位及其顶部和底部贴合视口，并持续 1 秒；仅出现“退出网页模式”不算成功。如果按钮处于退出状态而布局没有生效，先点击退出，等待 2 秒后再进入。已进入浏览器全屏时停止；成功后手动退出不强制恢复，初始化期间手动操作也会取消自动处理。最多等待 100 秒、点击 5 次（含重置），至少间隔 2 秒，离页清理监听和计时器。按当前官方播放器实现短暂触发右侧按钮提示以识别文案，不依赖按钮顺序或哈希类名；可能短暂出现提示。
- **自动最高画质**：视频元数据就绪后打开画质菜单，按官方菜单从高到低的顺序选择第一项可用画质，跳过“自动”、线路和画质增强，确认选中后结束。最多等待 100 秒、打开菜单 10 次、点击画质 3 次，打开或点击至少间隔 2 秒；可能短暂显示菜单。手动选择画质后停止本轮操作，离页清理监听和计时器，每次完整刷新重新执行。未登录时跳过提升画质，登录后刷新即可；可选上限以网站提供的菜单为准。
- **屏蔽等级和粉丝牌**：仅隐藏 `#chat-history-list .chat-item` 内的荣耀等级、旧版用户等级、粉丝勋章、团体勋章和特殊称号（`.title-label`），保留昵称、正文、房管标识及发送框自己的勋章按钮。CSS 同样作用于后续追加的弹幕，特殊称号沿用此开关。
- **屏蔽弹幕池顶部**：隐藏弹幕池内的排行榜、醒目留言入口、活动欢迎区、顶部活动卡片和聊天区顶部覆盖层；取消顶部覆盖层预留的列表空白，让聊天区用弹性布局填满剩余高度，保留底部发送框。此开关会隐藏顶部醒目留言卡片及礼物/进场覆盖层；不删除普通弹幕行。

选择器、播放器的“网页模式”提示、页面布局状态及画质菜单排序和登录限制已核对 [544618 直播间](https://live.bilibili.com/544618) 的公开 HTML、官方页面 JS/CSS 和官方播放器 JS。早期三项直播功能已实际试用，后续反馈发现自动网页模式偶发只切换按钮状态。1.3.2 的就绪延迟、实际布局确认、空模式重置、延迟响应、有限重试和手动取消已通过本地模拟检查，真实页面效果待重新试用确认。自动最高画质也通过延迟加载、菜单筛选、选中确认、登录状态、手动选择、有限重试和离页清理的模拟检查，实页效果待试用。

在仓库根目录运行 `node tests/bilibili-live.test.cjs` 可复查原有直播逻辑，以及动态、视频和稍后观看的页面分流；运行 `node tests/bilibili-live-quality.test.cjs` 可复查直播自动最高画质。
