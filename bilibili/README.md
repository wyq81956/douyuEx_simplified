# B站附属脚本

版本 **1.3.0**，一个油猴脚本包含动态、视频和直播间增强功能，六个开关默认开启，分别保存，无需编译。1.3.0 新增直播间自动最高画质；1.2.0 已支持直播间自动网页模式、弹幕等级和粉丝牌屏蔽、弹幕池顶部屏蔽；1.1.1 已支持“稍后观看”播放页。

## 安装与更新

使用同目录 [bilibiliex.user.js](bilibiliex.user.js) 的完整源码。在 Tampermonkey 中编辑已有脚本，用完整新代码覆盖并保存，再刷新对应页面。文件名统一为 `bilibiliex.user.js`，沿用原来的脚本名称、namespace 和存储键，保留原有设置；新增的自动最高画质默认开启。

首次使用时，安装并启用 Tampermonkey，打开 [脚本安装链接](https://raw.githubusercontent.com/wyq81956/douyuEx_simplified/master/bilibili/bilibiliex.user.js)。如果没有弹出安装页，在 Tampermonkey 中新建脚本，粘贴完整源码并保存即可。如果试装过单独的“B站视频 - 自动网页全屏”脚本，请停用或删除它。

油猴菜单提供六个独立开关，点击相应项目会保存并刷新页面，设置在刷新和重启浏览器后保留：

- 资料卡屏蔽（动态页）
- 自动网页全屏（视频页）
- 直播自动网页模式
- 直播弹幕等级和粉丝牌屏蔽
- 直播弹幕池顶部屏蔽
- 直播自动最高画质

## 动态：屏蔽悬浮用户资料卡

参考本项目斗鱼精简版的 CSS 屏蔽思路，在 `https://t.bilibili.com/*` 隐藏悬浮用户资料卡。刷新 [B站动态页](https://t.bilibili.com/)，把鼠标移到动态作者、转发作者等用户的头像上检查效果。

### 实现与范围

- 注入 CSS，隐藏 `.bili-user-profile` 和 `bili-user-profile`；不改动头像、昵称和它们的链接，也不拦截鼠标事件。
- 页面加载初期注入，规则自动作用于后续异步加载、滚动追加及重建的资料卡。
- 仅在 `t.bilibili.com` 顶层页面生效，不影响视频页或个人空间页。
- 无外部依赖、网络请求或账号设置修改。页面自身可能仍请求资料卡数据，本脚本只隐藏展示。

选择器参考 [B站共同关注快速查看的作者源码](https://greasyfork.org/zh-CN/scripts/428453-b%E7%AB%99%E5%85%B1%E5%90%8C%E5%85%B3%E6%B3%A8%E5%BF%AB%E9%80%9F%E6%9F%A5%E7%9C%8B/code) 的 `initDynamic()` 和 `initBiliUserProfile()`。已通过 JavaScript 语法和启用/停用逻辑检查，真实页面效果仍待试用；B站改版后可能需要调整选择器。

## 视频：自动网页全屏

在普通视频页 `https://www.bilibili.com/video/*` 和“稍后观看”播放页 `https://www.bilibili.com/list/watchlater/` 等待视频就绪，自动点击网站的网页全屏按钮，让播放器铺满浏览器网页区域。与资料卡屏蔽共用一个脚本，按页面地址启用对应功能；`bvid`、`oid` 等查询参数不影响启动判断。

### 行为与验证

- 通过 `.bpx-player-container` 的 `data-screen` 检查模式，再点击 `.bpx-player-ctrl-web`；已进入网页全屏或浏览器全屏时直接停止。
- 视频加载到元数据就绪后才尝试；不要求自动播放，也不修改画质、声音或播放状态。
- 每 500ms 检查一次，最多等待 100 秒；最多点击 3 次，至少间隔 2 秒。成功后结束，手动退出后不强制恢复。页面离开时清理计时器和监听。
- 初始化期间手动点击网页全屏、全屏或宽屏按钮，或在非输入区域使用 Esc/W/F/Q，会停止本次自动操作。
- 每次完整加载页面执行一轮；站内不刷新页面的换集或换视频不重新启动。覆盖普通视频页和“稍后观看”播放页，番剧页面暂不覆盖。

按钮和模式值参考 [bilibili H5播放器快捷操作的作者源码](https://greasyfork.org/en/scripts/26939-bilibili-h5%E6%92%AD%E6%94%BE%E5%99%A8%E5%BF%AB%E6%8D%B7%E6%93%8D%E4%BD%9C/code)。已检查语法及延迟加载、重复点击、已有全屏、手动操作和超时清理逻辑，并检查“稍后观看”地址的元数据匹配和功能启动；真实 B站页面效果尚待试用，网页改版可能需要调整。

## 直播间增强

适用于 `https://live.bilibili.com/数字房间号`，兼容 `/blanc/数字房间号`、末尾斜杠及查询参数；不处理直播首页和活动页。

- **自动网页模式**：播放器控件载入后，通过提示文字识别并点击“网页模式”，保留网站原有播放器与弹幕池布局。已处于网页模式或浏览器全屏时停止；手动退出后不强制恢复。最多等待 100 秒、点击 3 次，至少间隔 2 秒，离页清理监听和计时器。按当前官方播放器实现短暂触发右侧按钮提示以识别文案，不依赖按钮顺序或哈希类名；可能短暂出现提示。
- **自动最高画质**：视频元数据就绪后打开画质菜单，按官方菜单从高到低的顺序选择第一项可用画质，跳过“自动”、线路和画质增强，确认选中后结束。最多等待 100 秒、打开菜单 10 次、点击画质 3 次，打开或点击至少间隔 2 秒；可能短暂显示菜单。手动选择画质后停止本轮操作，离页清理监听和计时器，每次完整刷新重新执行。未登录时跳过提升画质，登录后刷新即可；可选上限以网站提供的菜单为准。
- **屏蔽等级和粉丝牌**：仅隐藏 `#chat-history-list .chat-item` 内的荣耀等级、旧版用户等级、粉丝勋章和团体勋章，保留昵称、正文、房管标识及发送框自己的勋章按钮。CSS 同样作用于后续追加的弹幕。
- **屏蔽弹幕池顶部**：隐藏弹幕池内的排行榜、醒目留言入口、活动欢迎区、顶部活动卡片和聊天区顶部覆盖层；取消顶部覆盖层预留的列表空白，让聊天区用弹性布局填满剩余高度，保留底部发送框。此开关会隐藏顶部醒目留言卡片及礼物/进场覆盖层；不删除普通弹幕行。

选择器、播放器的“网页模式”提示、`body.player-full-win` 状态及画质菜单排序和登录限制已核对 [544618 直播间](https://live.bilibili.com/544618) 的公开 HTML、官方页面 JS/CSS 和官方播放器 JS。1.2.0 的三项直播功能已获实际试用确认正常。自动最高画质通过本地模拟的延迟加载、菜单筛选、选中确认、登录状态、手动选择、有限重试和离页清理检查；此新增功能的真实页面效果待试用确认。

在仓库根目录运行 `node tests/bilibili-live.test.cjs` 可复查原有直播逻辑，以及动态、视频和稍后观看的页面分流；运行 `node tests/bilibili-live-quality.test.cjs` 可复查直播自动最高画质。
