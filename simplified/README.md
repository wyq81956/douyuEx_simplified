# DouyuEx 播放器精简版

当前版本 1.5.4，油猴菜单只保留“DouyuEx 设置”入口。点击后打开页面设置面板，集中提供八个开关：自动网页全屏、自动最高画质、简洁模式、屏蔽刀塔助手、拖动调整弹幕池、滚轮调音量、下播不跳转、关注页过滤，默认全部开启。

1.5.4 新增“关注页过滤”，独立于简洁模式：只在 [我的关注](https://www.douyu.com/directory/myFollow) 页面隐藏 `.layout-Banner`，以及包含指定状态文字的 `div.layout-Cover-card`。匹配规则为 `p` 含“上次直播”、`p` 含“预告”、`span` 含“轮播”，对应原 Adblock 规则；异步加载或状态改变时重新判断。更新已有脚本后刷新关注页即可，原有设置保留。

1.5.3 将开关和宽度复位迁入设置面板，原有设置保留。改动开关后点击“保存并刷新”才会保存并生效；取消、Esc 或点击面板外侧会放弃未保存的开关改动。“恢复弹幕池默认宽度”按钮立即执行，取消面板不撤销宽度复位。

1.5.2 新增“滚轮调音量”和“下播不跳转”，独立于简洁模式。用完整正式版覆盖已有脚本并刷新即可，原有设置保留。

“滚轮调音量”：鼠标放在音量按钮或滑条上，上滚增加 5%，下滚减少 5%，范围 0–100%；到 0 自动静音，非零取消静音。已静音但记住非零音量时，从记住的音量继续增减，沿用原版行为。Ctrl/Meta 加滚轮仍用于浏览器缩放，其他区域保留正常滚动。

“下播不跳转”：自动关闭下播推荐弹窗，阻止该弹窗的倒计时跳转，留在当前房间。只针对该弹窗，不拦截手动切换直播间或其他导航。与滚轮调音量均已获个人实际试用反馈正常。

1.5.1 已合并经个人实际试用确认正常的弹幕池拖动功能。停用拖动 Beta，用最新正式版覆盖已有正式版并启用；正式版保留原有设置，与 Beta 不共享存储，因此弹幕池宽度需重新拖动保存一次。两个 Beta 脚本及其说明文件已从当前版本移除，历史内容仍可在 Git 提交记录中查看。

“拖动调整弹幕池”独立控制分隔线和保存的宽度：向左拖加宽，向右拖缩窄，松手保存，双击恢复网站默认宽度。设置面板的“恢复弹幕池默认宽度”也可立即复位。拖动范围为 220–600px，最大宽度还受可用空间限制，保留网站规定的最小视频宽度。窗口缩小时临时收窄，变大后恢复偏好；弹幕池隐藏或空间不足时隐藏分隔线。分隔线获得键盘焦点后，左右方向键微调 10px，Shift 加方向键微调 50px，Home 复位。

“屏蔽刀塔助手”独立于简洁模式：隐藏播放器上的技能/物品悬停热区及描述弹窗，以及刀塔助手入口和提示窗。关闭此开关并刷新后恢复；不修改斗鱼账号设置，不影响主播战绩面板和第一视角入口。

“简洁模式”统一控制以下六项效果，一起开启或关闭：

- 隐藏礼物栏：让视频占用底部空间，同时隐藏原简洁模式中的 PK、点赞等相关浮层，保留视频播放控制栏。
- 拉高弹幕框：隐藏日榜/周榜和房间活动区域，让弹幕列表向上扩展。
- 隐藏弹幕前缀：隐藏弹幕列表中的粉丝牌、贵族图标和用户等级图标（`.js-user-level.UserLevel`）等装饰，保留昵称和正文。

- 屏蔽进场弹幕：隐藏弹幕框底部的进场信息区域，沿用原版的屏蔽范围，不过滤普通聊天中包含“进场”的文字。
- 屏蔽弹幕背景：去掉原版选择器匹配的飘屏弹幕背景、装饰图片和特效前缀，保留文字。
- 隐藏广告与推广：隐藏横幅、浮动广告、二维码推广、游戏推广和活动引导等；只隐藏网页元素，不拦截广告网络请求。

隐藏/屏蔽弹幕前缀是同一项效果，不重复处理。

## 使用

1. 在 Tampermonkey 中新建脚本，将同目录 `douyuEx_simplified.user.js` 的完整内容粘贴进去并保存。
2. 停用原版 DouyuEx，再刷新斗鱼直播间，避免两个脚本重复点击全屏按钮。
3. 在 Tampermonkey 菜单中点击“DouyuEx 设置”，在面板中调整开关后点击“保存并刷新”。

从旧版本更新时，在油猴中打开已有精简脚本，用新文件完整内容覆盖并保存即可，不要同时启用两份精简脚本。自动全屏/最高画质设置保留；合并后的简洁模式默认开启，旧版六个分项设置不再生效。关闭简洁模式并刷新，会同时恢复上述六项的页面原貌。

该文件已是可安装的独立脚本，无需 npm 安装或编译。后续直接维护此文件；不要用原项目的构建命令生成它。

1.4.0 已合并 Beta 的最高画质优化。试用 Beta 后请停用 Beta，用最新正式版覆盖原正式版脚本并启用。正式版沿用原来的名称、namespace 和设置；不会自动读取 Beta 的独立设置。

## 来源与范围

原始项目：https://github.com/qianjiachun/douyuEx ，作者：小淳。

自动播放相关的两个功能原本都在 `src/packages/ExpandTool/ExpandTool_FullScreen.js`：

- `initFullScreen()` / `fullScreen()`：读取设置，等待网页全屏按钮并点击。
- `initHighestVideoQuality()` / `highestVideoQuality()`：读取设置，点击画质列表第一项。

本版保留原始选择器和最高画质排序假设，移除了对扩展面板、公共函数和原版 localStorage 设置的依赖。使用独立的油猴存储，默认启用，不读取或修改原版设置。没有外部库、网络请求、统计或更新服务。

设置面板由 `openSettings()` 按需创建，用 Shadow DOM 隔离斗鱼样式，原生 `dialog.showModal()` 提供置顶、遮罩、焦点管理和 Esc 关闭。关闭时移除面板节点；仅“保存并刷新”写入八个开关的存储键，不改写已保存的弹幕池宽度。宽度复位直接调用拖动模块的 reset；拖动关闭时也能清除保存的宽度偏好。面板已在本地浏览器测试页检查旧设置读取、取消、Esc、保存刷新、宽度复位及样式隔离，需要支持 Shadow DOM 和 `dialog` 的现代浏览器。

关注页过滤由 `startFollowFilter()` 实现，根据用户提供的 Adblock 扩展规则改写，不依赖原版功能模块。设置键为 `followPage.filter`，默认开启；`isFollowPage()` 限定 `/directory/myFollow` 路径，兼容末尾 `/` 和查询参数，不等待直播 video。CSS 隐藏 banner；JavaScript 为匹配的卡片添加 `data-douyuex-follow-hidden`，匹配消失时撤销标记。MutationObserver 监听 body 的节点、文字和 class 更新，100ms 合并扫描，不监听自身标记以免循环。离页或检测到页面内导航离开关注页时清理观察器、计时器、标记和样式。只隐藏界面，不取消关注，也不请求直播状态接口；按指定标签文字匹配的范围与原规则一致。已通过 `node tests/follow-filter.test.cjs`，已获个人实际试用反馈正常。

自动全屏每秒尝试一次，最多 100 次，找到按钮后停止。网页全屏指播放器铺满浏览器网页区域。

最高画质立即检测菜单，并使用 MutationObserver（100ms 合并事件）及 250ms 轮询兜底，无需额外等待 video 节点。最高画质保持选中 2 秒后停止；两次点击至少间隔 2 秒，最多点击 5 次，达到上限后再等待 5 秒确认，总等待上限 100 秒。用户手动点击画质菜单时停止自动切换。停止时清理监听和计时器，不持续强制最高画质。

控制台筛选 `DouyuEx 画质` 可查看发现菜单、点击和停止的耗时。选中状态确认不代表直播流已切换或缓冲完毕，网络和播放器缓冲仍可能造成等待。

简洁模式提取自 `src/packages/Refresh/` 中的 `Refresh_Video.js`、`Refresh_BarrageFrame.js`、`Refresh_Barrage.js`。弹幕屏蔽提取自 `src/packages/Shield/RemoveEnter.js` 和 `RemoveDanmakuBackground.js`；广告隐藏选择器来自 `src/packages/RemoveAD/RemoveAD.js`，只保留广告/推广相关规则，不携带原版的登录提示、分享入口、滚动条修改等附加行为。

上述页面样式等待直播 video 节点出现后注入一次 CSS，持续作用于后续加载/重建的礼物栏、榜单、弹幕和广告节点；不依赖原版功能面板、弹窗库或设置。关闭对应开关并刷新即可恢复。等待最多 100 秒，没有检测到直播 video 时不注入；不是覆盖首页、鱼吧和视频站的全站广告拦截器。

礼物栏在网页全屏/浏览器全屏下的层级切换使用 CSS `:has()`，需使用支持该选择器的现代浏览器。其余规则仍依赖原版页面类名。

弹幕池拖动由 `startBarrageResize()` 接入新版布局，核对 `#js-player-main` 与弹幕池外层为同级，并通过 `--stage-sidebar-width` 统一调整视频、工具栏和弹幕区。初始化最多等待 100 秒；成功后 `ResizeObserver` 跟踪尺寸变化，每秒核对布局节点以支持网站重建，不监听每条弹幕更新。取消拖动或失去焦点时恢复拖动前宽度，离页时清理监听、计时器和注入样式。支持普通模式和弹幕池可见的网页全屏，不强制修改未知布局；浏览器全屏只包含视频时不显示分隔线。已通过 `node tests/barrage-resize.test.cjs`、浏览器布局检查及个人实际试用。

刀塔助手屏蔽由 `blockDotaHelper()` 独立注入 CSS，使用 9999 直播间核对的 `.tooltips-385829`、`.herosTooltips-16138a`、`.herosTooltipsPopover-93e2e9`、`.Dota2TipsDialog` 和 `.InteractItem[dataid="Dota2NewEntrance"]`。播放器公开源码 `gameHotArea/GameTips.js` 确认悬停弹窗属于该热区，因此隐藏热区可阻止鼠标触发；持续 CSS 也覆盖延迟加载或重建的节点。未使用范围更大的 `.liveos-workspace`，不隐藏整个播放器壳。只屏蔽界面交互，不停止助手后台脚本或数据请求；页面改版时需重新核对类名。选择器已核对实际 DOM 与源码，并经个人实际试用确认屏蔽有效。

滚轮调音量由 `startVolumeWheel()` 接入，提取自 `src/packages/VolumeMouseScrolling/VolumeMouseScrolling.{js,css}`。使用 document 捕获监听，仅匹配 `#js-player-main` 或 `.room-Player-Box` 内的 `.volume-07c230`，每次重新寻找直播 video，支持控件和视频重建。音量控件和新版共同容器已核对 9999 直播间 DOM。同步滑条、百分比和静音图标，并捕获 `volumechange` 跟随手动调整；只更新已有的 `volume_muted_before_key` 和 `player_storage_volume_h5p_room`，保留其余字段，损坏或受限存储不妨碍当前调音量。这些是斗鱼播放器自身存储，与原版扩展的功能设置无关。

下播不跳转由 `startNoCloseJump()` 接入，提取自 `src/packages/DisableCloseJump/DisableCloseJump.js`。立即检查并每秒点击可见、未禁用的 `.ClosingRecommend .dy-ModalRadius-close-x`，观看期间持续工作，不受 100 秒初始化期限限制。两个新功能离页时清理监听、样式或计时器。已通过 `node tests/playback-controls.test.cjs` 的事件范围、音量边界、静音、存储、节点重建、延迟弹窗和清理检查，并获个人实际试用反馈正常。

最高画质指原版逻辑中的列表第一项，不处理付费/登录权限，也不通过接口强制切换。选择器依赖斗鱼网页结构，网页改版后可能需要更新。全屏状态通过按钮文案识别，不能保证覆盖所有播放器版本。最高画质优化经个人实际试用反馈略有改善，尚未完成各类页面的完整兼容性验证。

原始源码和构建脚本保持不变，本目录独立维护。
