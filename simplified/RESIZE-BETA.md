# 弹幕池拖动试用版

> 此试用版已合并到正式版 **1.5.1**，并经个人实际试用确认正常。Beta 脚本已从当前版本移除，历史代码可在 Git 提交记录中查看。以下仅保留原试用说明；日常使用请更新 [正式版脚本](douyuEx_simplified.user.js) 并停用 Beta；设置不共享，正式版中的弹幕池宽度需重新拖动保存一次。

原文件：`douyuEx_simplified.resize-beta.user.js`（已移除），版本 **1.6.0-beta.1**。

基于正式版 1.5.0，保留自动网页全屏、最高画质、简洁模式和刀塔助手屏蔽，新增独立的“拖动调整弹幕池”开关。正式版与原版源码保持不变。

## 原安装与使用流程（历史记录）

1. 在 Tampermonkey 中新建脚本，粘贴试用版文件的完整代码并保存。
2. 停用正式版、旧的画质 Beta 和原版 DouyuEx，只启用本试用版，再刷新斗鱼直播间。
3. 试用版名称和 namespace 独立，设置与正式版不共享，五个开关默认开启。首次打开保留网站默认宽度。
4. 将鼠标移到视频和右侧弹幕池之间的细分隔线上，按住左键左右拖动。向左加宽弹幕池，向右缩窄，松手自动保存；宽度偏好适用于其他房间和下次打开。
5. 双击分隔线恢复网站默认宽度，也可以在油猴菜单中选择“恢复弹幕池默认宽度”。分隔线获得键盘焦点后，左右方向键微调 10px，按住 Shift 微调 50px，Home 复位。

关闭“拖动调整弹幕池”并刷新后恢复网站布局，保存的宽度仍保留，重新开启时继续使用。切回正式版时停用本试用版、启用正式版并刷新即可。

## 布局与限制

- 使用 9999 直播间核对的新版布局：`#js-player-main` 与弹幕池外层为同级，通过 `--stage-sidebar-width` 统一调整宽度，视频与工具栏跟随网站布局分配空间。
- 拖动范围为 220–600px，最大值还受播放器可用宽度限制，保留网站规定的最小视频宽度。窗口缩小时临时限制实际宽度，不覆盖保存的偏好；窗口变大时恢复。空间不足时恢复网站响应式布局并隐藏分隔线。
- 支持普通模式及弹幕池可见的网页全屏；弹幕池收起或隐藏时隐藏分隔线。单独视频的浏览器全屏通常没有右侧弹幕池，因此不提供分隔线。
- `ResizeObserver` 跟踪几何尺寸变化；播放器布局初始化最多等待 100 秒。成功接入后每秒只核对布局节点，支持网站重建节点，不监听每条弹幕的 DOM 更新。
- 松手、键盘微调后保存宽度；取消拖动、丢失指针捕获或窗口失去焦点时恢复拖动前宽度。通过动画帧合并播放器 `resize` 通知。
- 仅接入已核对的新版布局，不强制修改未知布局。斗鱼改版后可能需要适配。
